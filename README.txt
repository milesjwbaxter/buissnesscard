TREE HOUSE MULTI-PAGE WEBSITE

Open index.html to start. Keep site.css, site.js, and the assets folder next to the HTML pages. This is a static website that can be uploaded to GitHub Pages or another static host.

Pages: Home, Events, Concerts & Open Stage, Parties, Game Nights, Service, Temple Trips, Volunteer, Suggestion Box, Photos, and About.

The live event list reads the same public Google Apps Script endpoint as the supplied website and refreshes every five minutes while a page is open. Event objects use the existing date, name, and time fields; an optional description field is displayed when provided. The shared Google Sheet / Apps Script must remain published and public for the live feed to work.

Concert and open mic Google Forms are embedded in an accessible pop-up on the Concerts page. The suggestion box prepares a message and opens the Tree House Instagram profile for a manual DM. Direct form submission needs an official feedback form URL or email address; no destination was present in the supplied site code.
